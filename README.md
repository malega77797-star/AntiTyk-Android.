# АнтиТык

Экспериментальный Android блокировщик касаний для просмотра видео.

1. Установите PIN (4-8 цифр).
2. Дайте разрешение «Поверх других приложений» и уведомления.
3. Нажмите «Включить блокировку».
4. Для выхода: 3 касания в верхнем левом углу, затем удерживайте нижний правый угол 3 секунды и введите PIN.
5. Экстренный выход: действие «Выключить» в уведомлении.

**Ограничения:** системные жесты, шторка уведомлений, кнопка питания и системные экраны не блокируются. Это не полноценный родительский контроль. Приложение пока не протестировано на POCO X7 Pro / Android 16. PIN хранится локально без шифрования; не используйте важный PIN.

Сборка: GitHub Actions -> Build Android APK -> Artifacts -> AntiTyk-debug-apk.
